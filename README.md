# Movies-Website
Movies Website using HTML, CSS, and JavaScript. It includes:

🎬 Movies Hub

A simple and responsive Movies Website built using HTML, CSS, and JavaScript.
It displays movie cards and allows users to search movies instantly.


📌 Features

- 🎥 Display movie list in grid layout
- 🔍 Live search functionality
- 💻 Responsive design (mobile + desktop)
- 🎨 Clean and modern UI
- ⚡ Fast and lightweight (no frameworks)


🛠️ Tech Stack

- HTML5 – Structure
- CSS3 – Styling & layout
- JavaScript (Vanilla JS) – Logic & interactivity


📁 Project Structure

movies-site/
│── index.html
│── style.css
│── script.js


🚀 Getting Started

1. Clone or Download

git clone https://github.com/your-username/movies-site.git

2. Open Project

- Navigate to the folder
- Open "index.html" in your browser


🔎 How It Works

- Movies are stored in a JavaScript array
- JS dynamically creates movie cards
- Search input filters movies in real-time
